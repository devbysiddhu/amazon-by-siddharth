# 🛒 Amazon Clone
A frontend Amazon-inspired e-commerce website built from scratch using HTML and CSS. <br>
This project was created to practice and improve my skills in web design, HTML structure, CSS styling, layouts, and responsive design.

## 🚀 Live Demo
👉 https://amazon-by-siddharth.netlify.app/

## ✨ Features
- 🛍️ Amazon-inspired homepage design
- 🔍 Search bar and navigation section
- 📦 Product category sections
- 📚 Books and product sections
- 🖼️ Product cards with images and information
- 📱 Responsive and clean layout
- 🎨 Custom styling using CSS
- 📌 Footer with multiple sections

## 🛠️ Technologies Used
- HTML5
- CSS3

## 🎯 Purpose of the Project
The main purpose of this project was to practice building a real-world website interface using HTML and CSS without using any frontend framework.<br>
It helped me understand:
- HTML page structure
- CSS layouts
- Flexbox
- Grid
- Positioning
- Images and assets
- Navigation bars
- Product cards
- Website sections
- Responsive web design
